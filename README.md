# ♔ ChessOpenings

A free, offline chess opening trainer: 91 openings with move-by-move explanations. No account, no ads.

**[Play or download](https://primewaypoint.github.io/chess-openings/)**

## First launch

The desktop app is unsigned, so your system blocks it once.

- **Mac:** open Terminal and run `xattr -cr "/Applications/ChessOpenings.app"`, then open the app.
- **Windows:** click **More info** → **Run anyway**.
